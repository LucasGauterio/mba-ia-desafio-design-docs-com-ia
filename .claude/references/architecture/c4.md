# Reference · Modelo C4 (opcional)

O modelo C4 são quatro níveis de zoom para diagramas de arquitetura.
**Opcional neste pacote**: o enunciado não pede C4. Use no máximo um diagrama de Contexto
(C1) ou de Contêiner (C2) no FDD se ajudar a situar o módulo de webhooks; caso contrário,
pule.

## Os quatro níveis

| Nível | O que mostra | Público |
|---|---|---|
| **C1: Contexto** | O sistema como uma caixa, os atores e os sistemas externos com que fala | qualquer um |
| **C2: Contêiner** | As unidades executáveis/deployáveis (API, worker, banco) e como se comunicam | time técnico |
| **C3: Componente** | Decomposição interna de um contêiner em componentes e responsabilidades | quem implementa |
| **C4: Código** | Classes/estruturas concretas (raro; o código já é isso) | pontual |

## Se for usar (webhooks)

- **C1:** OMS ↔ Clientes B2B (Atlas, MaxDistribuição, Nova Cargo) recebendo webhooks;
  operadores usando a API.
- **C2:** `API HTTP` (Express) e `Webhook Worker` (processo separado, polling) como dois
  contêineres compartilhando o mesmo `MySQL`; o Worker faz HTTP de saída para os endpoints
  dos clientes.

Representar em Mermaid `flowchart` com subgraphs, seguindo os guardrails de `diagrams.md`.
Não criar um documento C4 separado; no máximo um bloco na seção "Diagramas" do
`docs/FDD.md`.
